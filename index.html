Shopify ⇄ Naviga File Converter

Turns the Matrixify order export into the Naviga (Magento-layout) order file, and the Naviga shipment file into a Matrixify fulfillment import.

🔒 Files are processed in this browser tab only. Nothing is uploaded.

Matrixify order export → Naviga order file

Drop the CSV exported from Matrixify (Orders). The output has the same 35 columns, order and formatting as the Magento export that Naviga imports today.

Naviga shipment file → Matrixify fulfillment import

Drop the shipping confirmation CSV from Naviga. Non-web orders (e.g. C CK 3540) are skipped, and multiple tracking numbers per order are merged.
