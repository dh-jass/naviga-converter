# Shopify ⇄ Naviga File Converter

A single-page tool that converts:

1. **Matrixify order export → Naviga order file** (same 35-column layout as the Magento export)
2. **Naviga shipment file → Matrixify fulfillment import**

It also includes a **Compare files** tab, which checks whether two CSVs match, and a **Test data** tab, which generates large test files.

Everything runs in the browser. Files are never uploaded anywhere.

## Hosting
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. The tool is `index.html`.
